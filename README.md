# ReactWeb

Frontend del ecosistema **DealRadar**, construido con React + TypeScript.

Panel web para consultar y gestionar anuncios y el estado de los scrapers, conectado a la API `NewApi` y al gateway `ScrapperGateway`.

**Stack:** React · TypeScript · APIs REST
**Repos relacionados:** NewApi · ScrapperGateway · SearchDaemon · dealradar
